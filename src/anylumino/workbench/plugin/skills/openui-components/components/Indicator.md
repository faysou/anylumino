# Indicator

A check, checkbox, or radio mark.

In Python: `ax.Indicator(value=...)`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `kind` | `"check" \| "checkbox" \| "radio"` | Which mark to draw. |
| `size` | `"sm" \| "md"` | Indicator size. |
| `disabled` | `boolean` | Whether the mark uses the disabled style. Indicators are not interactive. |
