# Timer

Elapsed time since it rendered.

In Python: `ax.Timer()`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `format` | `"elapsed" \| "clock"` | Elapsed `"1h 2m 3s"` or clock `"01:02:03"` text. |
| `text_type` | `string` | Semantic text type. |
| `size` | `string` | Explicit text-size override. |
| `color` | `string` | Text color. |
| `weight` | `string` | Font weight override. |
