# Timer

Elapsed time since it rendered.

In Python: `ax.Timer()`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `format` | `"elapsed" \| "clock"` | Elapsed `"1h 2m 3s"` or clock `"01:02:03"` text. |
| `text_type` | `"body" \| "large" \| "label" \| "supporting" \| "code" \| "display-1" \| "display-2" \| "display-3"` | Semantic text type. |
| `size` | `"4xs" \| "3xs" \| "2xs" \| "xsm" \| "sm" \| "base" \| "lg" \| "xl" \| "2xl" \| "3xl" \| "4xl"` | Explicit text-size override. |
| `color` | `"primary" \| "secondary" \| "disabled" \| "placeholder" \| "accent" \| "inherit"` | Text color. |
| `weight` | `"normal" \| "medium" \| "semibold" \| "bold"` | Font weight override. |
