# Slider options

A numeric slider; on_change runs with the new number.

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `label_position` | `"top" \| "left"` | Place the label above the slider or beside it in a compact row. |
| `label_width` | `number \| string` | Width of a left-side label. Use the same width to align sibling sliders. |
| `disabled` | `boolean` | Whether the component should render disabled. |
| `orientation` | `"horizontal" \| "vertical"` | Horizontal or vertical orientation. |
| `value_display` | `"tooltip" \| "text" \| "none"` | Tooltip, text, or hidden value presentation. |
| `marks` | `object[]` | Optional slider tick-mark records. |
| `description` | `string` | Helper text displayed with the slider. |
| `status` | `object` | Validation status record. |
