# Text options

A run of plain text.

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `text_type` | `"body" \| "large" \| "label" \| "supporting" \| "code" \| "display-1" \| "display-2" \| "display-3"` | Semantic Astryx text type, such as `"body"`, `"supporting"`, or `"display-1"`. |
| `size` | `"4xs" \| "3xs" \| "2xs" \| "xsm" \| "sm" \| "base" \| "lg" \| "xl" \| "2xl" \| "3xl" \| "4xl"` | Explicit font-size override. |
| `color` | `"primary" \| "secondary" \| "disabled" \| "placeholder" \| "accent" \| "inherit"` | Theme text color. |
| `weight` | `"normal" \| "medium" \| "semibold" \| "bold"` | Font-weight override. |
| `display` | `"inline" \| "block"` | Inline or block display mode. |
| `max_lines` | `number` | Maximum rendered lines before truncation. |
| `text_wrap` | `"wrap" \| "nowrap" \| "balance" \| "pretty"` | Text wrapping behavior. |
| `justify` | `"start" \| "center" \| "end"` | Logical text alignment. |
| `tabular_numbers` | `boolean` | Whether numeric glyphs use tabular widths. |
