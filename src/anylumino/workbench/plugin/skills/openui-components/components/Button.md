# Button

A button that runs its action when clicked.

In Python: `ax.Button(label=..., variant=...)`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `disabled` | `boolean` | Whether the component should render disabled. |
| `size` | `"sm" \| "md" \| "lg"` | Button size. |
| `loading` | `boolean` | Whether to show the loading state. |
| `tooltip` | `string` | Hover tooltip text. |
