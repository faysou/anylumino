# Checkbox options

A checkbox; on_change runs with true or false.

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `disabled` | `boolean` | Whether the component should render disabled. |
| `size` | `"sm" \| "md"` | Checkbox size. |
| `label_hidden` | `boolean` | Whether to visually hide the accessible label. |
| `description` | `string` | Helper text displayed below the label. |
| `loading` | `boolean` | Whether to show the loading state. |
| `read_only` | `boolean` | Whether interaction is disabled without dimming the value. |
| `status` | `object` | Validation status record. |
