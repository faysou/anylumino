# Card

A bordered surface around its children.

In Python: `ax.Card(children=...)`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `variant` | `"default" \| "muted" \| "blue" \| "cyan" \| "gray" \| "green" \| "orange" \| "pink" \| "purple" \| "red" \| "teal" \| "yellow"` | Astryx visual variant. |
| `padding` | `number` | Inner padding using the Astryx spacing scale. |
| `width` | `number \| string` | Card width. |
| `height` | `number \| string` | Card height. |
| `max_width` | `number \| string` | Maximum card width. |
| `min_height` | `number \| string` | Minimum card height. |
