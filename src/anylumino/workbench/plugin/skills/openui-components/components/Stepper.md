# Stepper

Ordered steps; value is the zero-based active step.

In Python: `ax.Stepper(items=..., value=...)`, plus any option below as a keyword.

## Options

| Option | Type | Meaning |
| ------ | ---- | ------- |
| `label` | `string` | Accessible label of the stepper. |
| `orientation` | `"horizontal" \| "vertical"` | Horizontal or vertical layout. |
| `density` | `"compact" \| "balanced" \| "spacious"` | Spacing between steps. |
| `navigable` | `boolean` | Whether clicking a step makes it active. |
