title: "Chat"
---

Render a chat thread and composer from a Python-owned message list.

<Callout title="Notes" type="note">
  Assigning `messages` replaces the list; mutating it in place does not
  sync. To stream a reply, replace the last message with its longer
  content::

  ```
  chat.messages = [*chat.messages[:-1], {"role": "assistant", "content": text}]
  ```

  Submitting does not append the user message. Submit callbacks decide what
  the thread shows.

  See Astryx component docs: [https://astryx.atmeta.com/components/ChatLayout](https://astryx.atmeta.com/components/ChatLayout).
</Callout>

  <div>
    <PyParameter name="messages" type="Iterable[Mapping[str, Any]]" value="()">
      Messages in display order. Each message has a `role` of `"user"`,
      `"assistant"`, or `"system"`, Markdown `content`, an optional
      `status` of `"sending"`, `"sent"`, `"error"`, or `"stopped"`,
      and optional `tool_calls`. Each tool call has a `name`, an optional
      `target`, and a `status` of `"pending"`, `"running"`,
      `"complete"`, or `"error"`.
    </PyParameter>

    <PyParameter name="is_streaming" type="bool" value="False">
      Whether an assistant turn is in progress. While it is, the composer
      shows a stop control instead of the send button, and the last
      assistant message renders in streaming mode.
    </PyParameter>

    <PyParameter name="placeholder" type="str" value="''">
      Composer placeholder. Empty uses the Astryx default.
    </PyParameter>

    <PyParameter name="disabled" type="bool" value="False">
      Whether the composer is disabled. A disabled chat ignores submits.
    </PyParameter>

    <PyParameter name="width" type="int | float | str | None" value="None">

    </PyParameter>

    <PyParameter name="height" type="int | float | str | None" value="480">

      definite value. Numbers are normalized by anylumino where supported.

<PyFunction name="on_submit" type="(callback, remove=False) -> None">
  Register or unregister a callback receiving the chat and the submitted text.

  <PySourceCode>
    ```python
    def on_submit(
        self,
        callback: Callable[[Chat, str], None],
        remove: bool = False,
    ) -> None:
        """Register or unregister a callback receiving the chat and the submitted text."""
        if remove:
            self._submit_callbacks = [
                item for item in self._submit_callbacks if item is not callback
            ]
            return
        self._submit_callbacks.append(callback)
    ```
