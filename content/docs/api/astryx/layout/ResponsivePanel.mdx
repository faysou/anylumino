---
title: "ResponsivePanel"
---

Astryx stack that switches direction when its width crosses a breakpoint.

```python
ax.ResponsivePanel(
    [ax.Card(ax.Text("Controls"), padding=3), ax.Card(ax.Text("Chart"), padding=3)],
    breakpoint=600,
)
```
