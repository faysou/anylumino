---
title: "Overlay"
---

Render content over a base Astryx surface or media widget.

```python
ax.Overlay(
    ax.Card(ax.Text("Market preview"), padding=4, width=220),
    ax.Button("Quick view", variant="ghost"),
    show_on="always",
    position="bottom",
)
```
