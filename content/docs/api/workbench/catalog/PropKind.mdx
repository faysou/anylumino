What a catalog prop holds.

## Attributes

<PyAttributes>
  <PyAttribute name="VALUE" value="'value'">
    A constructor keyword.
  </PyAttribute>

  <PyAttribute name="CHILDREN" value="'children'">
    A slot of components.
  </PyAttribute>

  <PyAttribute name="ACTION" value="'action'">
    An OpenUI action.
  </PyAttribute>

  <PyAttribute name="OPTIONS" value="'options'">
    The object of extra constructor keywords that ends every widget component.
  </PyAttribute>
</PyAttributes>
