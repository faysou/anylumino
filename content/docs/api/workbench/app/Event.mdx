title: "Event"
---

A widget event passed to a handler.

## Attributes

<PyAttributes>
  <PyAttribute name="source" type="str">
    The statement name of the component that fired.
  </PyAttribute>

  <PyAttribute name="value" type="Any" value="None">
    The new value for a value change, or `None` for a click.
  </PyAttribute>

  <PyAttribute name="context" type="Any" value="None">
    The second `@Callback` argument, or `None`.
  </PyAttribute>
</PyAttributes>
