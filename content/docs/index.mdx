`anylumino` is a small Python package for building notebook interfaces where
Lumino layout widgets arrange child anywidgets and Astryx components provide
the application UI.

The core idea is direct composition:

```python
import anylumino as al
import anylumino.astryx as ax

brand = ax.Brand(
    "desk",
    **{
        "color-accent": ("#0057b8", "#79b8ff"),
        "color-background-card": ("#ffffff", "#111827"),
        "radius-container": "8px",
    },
)

orders = ax.Table(
    rows=order_rows,
    columns={"order_id": "Order", "symbol": "Symbol", "qty": "Qty", "status": "Status"},
    row_key="order_id",
    selects="multiple",
    sortable=True,
)

controls = ax.Theme(
    {
        "symbol": ax.Typeahead(
            ["AAPL", "MSFT", "NVDA"],
            value="AAPL",
            label="Symbol",
        ),
        "fields": ax.Tokenizer(
            ["Bid", "Ask", "Last"],
            value=["Bid", "Ask"],
            label="Fields",
        ),
        "refresh": ax.Button("Refresh", variant="primary"),
    },
    brand=brand,
    gap=3,
)

tabs = al.TabPanel({"orders": orders, "chart": trend_figure})
al.SplitPanel({"controls": controls, "workspace": tabs}, sizes=[0.25, 0.75])
```

## What it provides

## Layouts

- `TabPanel` for tabbed child widgets.
- `BoxPanel`, `HBox`, `VBox`, and `ScrollBox` for linear composition.
- `SplitPanel` for drag-adjustable panes.
- `DockPanel`, `AccordionPanel`, `StackedPanel`, `GridPanel`, and
  `ResponsivePanel` for application-like notebook layouts.

## Actions

- `Toolbar` for compact command rows.
- `MenuBar` for grouped commands.
- `CommandPalette` for inline notebook-safe searchable commands.
- `CommandPalette` for Lumino-style searchable actions.

Each action can dispatch to a Python callback.

## Controls

`anylumino` includes Astryx wrappers for buttons, text inputs, selectors,
tokenizers, segmented controls, tables, status surfaces, popovers, inline
dialogs, and reusable brand themes.

## Design model

`anylumino` is designed around `LayoutWidget`, the shared base class for layout
containers. A layout can be declared with a dictionary, and those keys become
the stable access path from Python:

```python
tabs = TabPanel({"trend": trend_panel, "samples": samples_table})
tabs.select_key("samples")
tabs["trend"].refresh()
tabs.call_owner("trend", "refresh")
```

That lets a dashboard own layout, state, and behavior without relying on global
variables.
